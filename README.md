# Kuwait Weekend Explorer

A simple one-page practice website that shows weekend destinations in Kuwait.

## Files

- `index.html`: the page structure and content (title, description, destination cards)
- `styles.css`: the visual design (colors, layout, fonts, hover effects)

## Run it locally

**Option 1: just open the file**
Double-click `index.html`. It opens in your web browser.

**Option 2: use a local web server** (needs Python installed)

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser. Press `Ctrl+C` in the terminal to stop the server.
